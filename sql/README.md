# SQL Analysis

## Overview

This folder contains the SQL analysis used to examine the quality and structure of the IT service management data and investigate operational performance.

The analysis focuses on understanding how incidents are handled, how long they take to resolve and whether repeated reassignments or handling activities are associated with operational inefficiencies.

## Analysis Covered

- **Data validation:** Checking incident records, unique identifiers, missing values and data consistency.
- **Resolution performance:** Examining incident resolution times and identifying cases with unusually long durations.
- **Incident reassignments:** Investigating how frequently incidents are transferred between support teams.
- **Handling activity:** Assessing the number of recorded events associated with individual incidents.
- **Operational performance:** Producing summary measures that support further analysis and management reporting.

## Purpose

The SQL analysis provides a reliable starting point for the wider assessment. Its findings support the subsequent Python analysis and Power BI dashboards, helping ensure that management recommendations are based on validated data rather than assumptions.

The focus is not simply on producing queries, but on using the results to identify operational issues that warrant further investigation.
